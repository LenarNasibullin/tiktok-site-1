# TikSave: как добавлять страницы и статьи

Каждая страница это текстовый файл в папке `content/tr/`. После загрузки в GitHub Vercel сам собирает сайт.

## Новая статья
1. Создайте файл в `content/tr/blog/`, например `content/tr/blog/moya-statya.md`. Имя файла станет адресом: /blog/moya-statya/
2. В начале файла укажите данные между строками `---`:

```
---
title: Заголовок для Google (до 60 символов)
description: Описание для Google (до 155 символов)
h1: Заголовок на странице
date: 2026-11-01
---
Текст статьи. Подзаголовки: ## Подзаголовок
Списки: - пункт или 1. пункт
Ссылка: [текст](/адрес/)
Картинка: ![описание](/images/файл.png)
```

3. Чтобы статью сначала проверить, добавьте строку `draft: true`. Пока она есть, статья на сайте не появится. Когда всё готово, удалите строку.

## Новая обычная страница
Файл в `content/tr/` (не в blog). Чтобы на странице была форма скачивания, поставьте на отдельной строке `{{tool}}`. Не забудьте добавить страницу в меню в `site.config.json`.

## Картинки
Положите в папку `static/images/`, ссылка в тексте: `/images/имя.png`.

## Новый язык
Создайте папку `content/en/` с такими же файлами. В `key:` у переведённых страниц ставьте то же значение, что у оригинала, тогда hreflang подключится сам. Меню и подвал для языка добавьте в `site.config.json`.

## Адрес сайта
В `site.config.json` замените `siteUrl` на ваш домен. Без этого canonical и sitemap.xml не создаются.
